# Follow-up automatico com IA

Template publico da XMACNA para desenhar follow-up comercial com agente de IA, sem transformar relacionamento em disparo frio.

O foco e cadencia inteligente: contexto, proximo passo, respeito ao interesse do lead, registro no Painel Inteligente e passagem para humano quando houver sinal de compra.

Site oficial: https://xmacna.ai  
IA para vendas B2B: https://xmacna.ai/ia-para-vendas-b2b  
Agente de IA para WhatsApp: https://xmacna.ai/sdr-com-ia  
Funcionarios Digitais com IA: https://xmacna.ai/funcionario-digital

## Regra de uso

Use apenas com leads que ja tenham relacao, interesse, origem ou base legal adequada. Nao usar para spam, disparo em massa, compra de lista ou insistencia sem contexto.
